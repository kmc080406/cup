# 컵체크. — CODEMATE

**종이컵 · 플라스틱컵 · 아무것도 없음**을 카메라 사진으로 구분하는 동아리 체험 웹사이트입니다.

## 체험하기

https://kmc080406.github.io/cup/?v=4

1. **시작하기**를 누른 뒤 카메라 사용을 허용합니다.
2. 종이컵이나 플라스틱컵을 화면 중앙에 비춥니다.
3. **사진 찍기**를 누르면 그 순간의 사진이 화면에 고정됩니다.
4. AI가 고정된 사진을 분석해 **종이컵 / 플라스틱컵 / 아무것도 없음**(컵을 찾지 못한 경우)을 표시합니다. 분류가 모호하면 **판별 어려움**으로 표시할 수 있습니다.
5. **다시 촬영**을 누르면 실시간 카메라로 돌아갑니다. 휴대폰에서 전·후면 카메라를 전환할 수 있습니다.

**실시간 화면의 매 프레임을 분석하지 않습니다.** 촬영 버튼을 누를 때에만 추론하므로 결과가 계속 바뀌지 않습니다.

## 판별 방식

- Google MediaPipe EfficientDet-Lite0으로 **촬영한 정지 사진에서 컵이 있는지 탐지**합니다.
- 컵이 보이면 그 영역을 좁게/넓게 두 번 크롭해 MobileCLIP-S0으로 분석한 결과를 결합합니다.
- 컵이 보이지 않으면 **아무것도 없음**을 표시합니다.
- 점수나 백분율은 사용자 화면에 표시하지 않습니다.
- **시연용 사진 예시 등록** 기능을 제공합니다. 사진을 촬영한 뒤 결과가 틀렸다면 **이용 안내 → 이 사진은 종이컵 / 이 사진은 플라스틱컵**으로 AI 특징 벡터를 저장할 수 있습니다. 다양한 각도에서 2~3장씩 등록하면 그 컵들과의 비교에 도움이 됩니다.

## 제약

이 웹사이트는 **물리적 재질을 직접 측정하지 않습니다.** 학습된 이미지 특징을 이용해 외관만 추정합니다. 코팅된 종이컵이나 불투명 플라스틱컵, 배경이 복잡한 장면, 컵 탐지 실패에서는 잘못 분류할 수 있습니다. 특히 사진 예시를 등록해도 일반적인 정확도가 보장되는 것은 아닙니다. 발표에서 사용할 실제 컵으로 반드시 시험해 주세요.

카메라 사진/동영상은 서버에 전송하거나 저장하지 않습니다. 사진 예시를 등록할 경우 원본 사진 대신 정규화된 숫자 특징만 **이 브라우저의 로컬 저장소**에 저장합니다. 버튼으로 초기화할 수 있습니다. 초기 모델 다운로드에는 인터넷 연결이 필요합니다.
